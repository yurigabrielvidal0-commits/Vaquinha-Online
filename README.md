# Vaquinha Online

Visual baseado na vaquinha anterior, com pagamento Pix via LunarPay.

No Render:
- Build Command: `npm install`
- Start Command: `npm start`

Variáveis:
- `LUNARPAY_API_KEY` = sua chave secreta da LunarPay
- `PUBLIC_URL` = URL pública do Render (recomendado)

Nunca coloque a API key no `index.html` ou em código do navegador.
